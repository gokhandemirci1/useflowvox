# FlowVox AI Portfolyo Sitesi

FlowVox AI şirketi için modern ve responsive bir portfolyo web sitesi.

## Özellikler

- 🎨 Modern ve şık tasarım
- 📱 Tam responsive (mobil uyumlu)
- ⚡ Hızlı ve optimize edilmiş
- 🎯 Smooth scroll navigasyon
- 🌈 Gradient renkler ve animasyonlar

## Teknolojiler

- React 18
- Vite
- Tailwind CSS
- Modern ES6+ JavaScript

## Kurulum

1. Bağımlılıkları yükleyin:
```bash
npm install
```

2. Geliştirme sunucusunu başlatın:
```bash
npm run dev
```

3. Tarayıcınızda `http://localhost:5173` adresini açın.

## Build

Production build için:
```bash
npm run build
```

Build edilmiş dosyalar `dist` klasöründe olacaktır.

## Bölümler

- **Ana Sayfa (Hero)**: Etkileyici giriş bölümü
- **Ne Yaptığımız**: Hizmetler ve çözümler
- **Hakkımızda**: Şirket misyonu, vizyonu ve değerleri
- **İletişim**: Footer bölümünde iletişim bilgileri

## Özelleştirme

- Renkleri değiştirmek için `tailwind.config.js` dosyasındaki `primary` renk paletini düzenleyin
- İçerikleri değiştirmek için `src/components/` klasöründeki ilgili bileşen dosyalarını düzenleyin
- İletişim bilgilerini `src/components/Footer.jsx` dosyasında güncelleyin
